    • 命名规范

    命名规范#

    规范例子
    sub消息号1.驼峰式命名kSubQueryGoldRooms
    2.kSub 表示client->server
    3.kCmd 表示server->client
    结构体消息号去掉前缀’k'SubQueryGoldRooms
    处理函数消息号去掉前缀’k'SubQueryGoldRooms

    消息号 含义

    1. 第一个字段 k. 表示常量
    2. 第二个字段 归属标志. 可能的赋值:
      • Sub Client向Server查询
      • Cmd Server返回给Client
    3. 第三个字段 意图 增删改查
    4. 第四个字段 对象 被op对象 – 可以没有
    5. 第五个字段 消息号含义
