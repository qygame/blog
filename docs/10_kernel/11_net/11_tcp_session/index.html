    传输格式#

    tcp 传输格式见 TcpHead

    回调设置#

    1. TcpClient
      • socket::Connected -> SubResit2Server
      • socket::Closed -> EventInterface::OnClosed
      • socker::Read -> MessageCallback
    2. TcpServerSession
      • socket::Connected -> 不做任何处理
      • socket::Closed -> EventInterface::OnClosed
      • socket::Read -> MessageCallback

    MessageCallback 逻辑

    1. SubResit2Server 消息
      返回注册成功 CmdResit2Server;
      通知 EventInterface::OnConnected

      只有TcpClient 会向TcpServer 发送注册消息.
      收到注册消息后, TcpServer才会认为与TcpClient连接成功. (与socket的连接成功不一样)

    2. CmdResit2Server 消息
      通知 EventInterface::OnConnected

      只有收到注册成功消息后, client才会认为与server连接成功. (与socket的连接成功不一样)

    3. rpc 消息
      TODO 后续补充逻辑

    4. 其他消息
      转发给 EventInterface::OnRead 处理
