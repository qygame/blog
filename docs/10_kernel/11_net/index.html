    net多线程 注意事项#

    1. 不要捕获this, 使用shared_ptr代替
      this 只是一个地址, 如果对象内存摧毁后, 会变成悬空指针
      智能指针可以保证, 只要智能指针还在, 对象的内存就不会被摧毁
    2. 为了避免work 与 io 线程竞争, 不要传递this. 尽量使用副本(thread local)
    3. 为了避免多线程io_context 竞争, 使用strand, 即使io_context 是单线程, 也推荐strand
    4. 为了避免线程之间的数据copy. 使用 unique_ptr + std::move

    回调设置#

    1. EventInterface 对上层接口
      • EventInterface::OnRead: 读取到消息
      • EventInterface::OnClosed: session 关闭
      • EventInterface::OnConnected: session 连接成功
    2. client socket
      • Connected -> Resit2Server
      • Closed -> EventInterface::OnClosed
      • Read Message -> MessageCallback
    3. server socket
      • Connected -> 不做任何处理
      • Closed -> EventInterface::OnClosed
      • Read Message -> MessageCallback

    MessageCallback 逻辑

    1. 注册 消息
      返回注册成功;
      通知 EventInterface::OnConnected

      因为只有client 会向server 发送注册消息.
只有收到注册消息后, server才会认为与client连接成功. (与socket的连接成功不一样)

    2. 注册完成 消息
      通知 EventInterface::OnConnected

      只有收到注册成功消息后, client才会认为与server连接成功. (与socket的连接成功不一样)

    4. 其他消息
      转发给 EventInterface::OnRead 处理
