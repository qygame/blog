    多线程涉及的模块#

    推荐使用 底层多线程 + 业务单线程

    底层都是通过把callback() post 到work 线程, 从而避免业务层出现多线程问题

    底层自身使用了多线程的模块:

    1. net/client, server 使用strand_ 来解决自身的多线程问题,
    2. net/timer 使用strand_ 来解决自身的多线程问题

    底层可能被 多线程的业务层 调用的模块:

    1. database
      只有DbServer 才可能是多线程.
      database 使用锁来保护自己的数据(数据库连接)
