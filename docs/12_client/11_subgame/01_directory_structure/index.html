      目录结构#

      子游戏统一存放在项目根目录下的subgames目录中,
      每个子游戏使用对应的 kindid 作为目录名称, 实现子游戏之间的目录隔离

      |-- addons              // 插件
|-- proto               // proto文件
|-- scene               // 场景
|-- scripts             // 脚本
|-- subgames            // 子游戏
|   |-- 11              //
|   `-- 22              //
|-- third_party         // 第三方库
`-- project.godot       //

      每个子游戏独立管理自身的场景、资源、Protocol Buffer 定义及脚本文件
      子游戏之间保持目录隔离，避免资源和业务逻辑相互耦合

      11                              //
├── assets                      // 资源目录
├── proto                       // 子游戏使用的proto
├── scripts                     //
│   ├── 11.gd                   // SubGame
│   ├── constant.gd             // client自己使用的常量定义
│   ├── data.gd                 // Data
│   ├── message_handler.gd      // 消息处理
│   ├── sub_flow.gd             // Flow
│   └── sub_ui.gd               // UI
└── 11.tscn                     // 场景
