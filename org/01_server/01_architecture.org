* 服务器架构
  #+begin_src mermaid :file result.png
    architecture-beta
    %% client
    service client(internet)[Client]

    %% Server
    group servers(server)[Servers]
    service gate(server)[Gate] in servers
    service room(server)[Room] in servers
    gate:R <-- L:room

    %% 数据层
    group dbs(database)[Databses]
    service redis(database)[Redis] in dbs
    service postgres(database)[Postgres] in dbs
    redis:R -- L:postgres

    %% 指向
    client:R --> L:gate

    gate:B --> T:redis{group}
  #+end_src


* 服务器说明

  #+begin_example
    [ 客户端 Client ]
           │
           │ 1. DNS / Anycast 将域名解析分发给不同的 LB IP
           ▼
    [ LB 集群 (Nginx / Cloud NLB) ] ── (第一层负载：入口分流、解密 HTTPS)
           │
           │ 2. LB 通过 HTTP 轮询转发给不同的 LoginServer
           ▼
    [ LoginServer 集群 ]            ── (第二层负载：无状态鉴权、业务逻辑计算)
           │
           │ 3. Login 查 Redis 挑选最空闲的 Gate，把 Gate IP 返回给 Client
           ▼
    [ GateServer 集群 ]             ── (第三层负载：重定向直连，平摊海量长连接)
           │
           │ 4. Gate 根据 RoleID 通过一致性 Hash 路由给指定的 Actor
           ▼
    [ ActorServer 集群 ]           ── (第四层负载：有状态计算，按 RoleID 动态加载)
  #+end_example
