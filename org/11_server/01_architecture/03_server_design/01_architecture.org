* 设计思想
  1. =分层、集群= 是对资源的妥协, 是出于 =部署= 需求, 才引入的设计手段, 而不是架构设计的最终目的
     分层用于拆分部署单元, 集群用于扩展计算能力
     如果计算资源是无限的, 就不再需要分层、集群

  2. 对于服务器设计, 最重要的不是分层、集群, 而是 =故障恢复=
     服务器不可避免地会发生错误、崩溃甚至机器故障
     架构设计需要重点考虑故障发生后, 如何重新拉起服务、恢复运行状态, 以及恢复服务之间的协作关系
