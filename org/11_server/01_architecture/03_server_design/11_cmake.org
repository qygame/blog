#+title: Server 管理


通过容器来管理Server.
CMake 生成Server target 的时候, 会把Server target 及其依赖项(动态库, 配置文件) 放到相应的容器中.

比如 gate server:
#+begin_example
  gate server
  |-- qy_gate           // Server target
  |-- qy_gate.debug     // 符号表
  |-- conf              // 配置文件目录
  `-- lib               // 动态库目录
#+end_example

CMake 会生成容器qy_gate, 并把gate server 目录下的所有文件copy 到/app 中.
同时设置/app/lib 到lib 运行路径, 并启动容器的时候运行/app/qy_gate

* 基础容器
  gate server/lib 中已经包含了qy_gate 的运行依赖, 所以基础容器不再需要
  应该选择精简的运行容器, 现在的方案是 gcr.io/distroless/cc-debian13:nonroot
