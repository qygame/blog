* 基础概念

  1. =module=: 独立的业务单元
     拥有清晰的业务边界, 负责业务规则, 状态管理和领域逻辑
  2. =service=: 业务请求处理对象
     负责接受请求, 协议适配, 参数校验, 调用业务模块, 组织响应
     依赖一个或多个 =module=
  3. =Endpoint=: 访问 Service 的入口
     负责把请求分发到对应的Service
  4. =executor=: 负责消息队列管理, 任务调度

  -----

* 代码组织目录
  代码应该按照 service - module 的层级进行设计. 例如src 目录应该为:
  #+begin_example
    |-- common                  //
    |   |-- runtime             // runtime基础设施
    |   |   |-- service_manager //
    |   |   |-- endpoint        //
    |   |   |-- executor        //
    |-- service                 //
    |   |-- room                // room service
    |   |   |-- module          //
    |   |   |   |-- config      // config module
    |   |   |   `-- table       // table module
    |   |   `-- tools           //
    |   `-- actor               // actor service
    `-- CMakeLists.txt          //
  #+end_example
