#+title: 服务器设计中基础概念


* 基础概念
  1. =server=: 服务器运行实例
     关注部署, 进程, 资源和运行环境
     可以有多个service

-----

* 代码组织目录
  代码应该在 src/server 中
  #+begin_example
    |-- common                  //
    |-- service                 //
    |-- server                  //
    |   |-- gate_server         // gate server
    |   `-- room_server         // room server
    `-- CMakeLists.txt          //
  #+end_example
