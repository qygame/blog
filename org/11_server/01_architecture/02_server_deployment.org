服务器架构设计决定了每个Server 的职责边界, 决定了每个Server在代码层面和设计层面的独立性

但实际部署的时候, 应该根据实际情况来自行决定.

考虑到当前业务规模及服务器承载压力较小, 对服务器架构进行了适当简化, 将多个独立服务器合并部署到 GateServer.

本次架构调整如下:
1. 去除LoginServer
2. ActorServer合并进GateServer
3. GameServer 合并进GateServer
4. TaskServer 合并进GateServer
5. RankServer 合并进GateServer
6. MatchServer 合并进GateServer


#+attr_shortcode: info
#+begin_hint
虽然在服务器部署层面, 原本独立的服务器都合并到了 GateServer, 但这只是部署架构上的简化, 并不意味着Server职责和代码结构的合并
- 职责独立: 各Server负责自身的业务逻辑, 不因部署位置而改变职责边界
- 代码独立: 各Server保持独立的代码组织和实现, 不将不同Server的业务逻辑混合
- 接口协作: Server之间通过明确的接口进行交互, 避免直接耦合其他Server的内部实现

#+end_hint
