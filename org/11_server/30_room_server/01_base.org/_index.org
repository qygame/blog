将现实中的游戏（如打牌、下棋等）抽象为统一的数据模型

本部分主要定义游戏中的基础抽象概念, 明确各个模型的数据结构、属性及职责边界.
例如, 桌子（Table）应该具备哪些属性, 房间规则（RoomRule）应该如何定义, 以及各个模型之间如何协作.
