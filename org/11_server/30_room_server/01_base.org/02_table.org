* 概念
  =桌子Table= 是游戏过程中的核心承载实体, 用于组织和管理参与同一场游戏的玩家.

  Table 是一个高度抽象的概念, 不特指某一种游戏. 无论是棋牌类游戏(如斗地主、象棋), 还是竞技类游戏(如王者荣耀), 都可以抽象为一张桌子

  不同游戏的具体玩法和交互方式可能不同, 但从服务端的视角来看, 都可以抽象为相似的游戏生命周期

  #+begin_src mermaid :file result.png

  因此, Table 只关注游戏过程中的通用概念和生命周期, 不关心具体游戏的玩法细节. 具体游戏的差异由对应的游戏逻辑负责处理



* 与房间规则关系
  桌子需要依赖游戏规则才能运行, 而房间规则(RoomRule)负责定义一场游戏所使用的规则及配置

  RoomRule 是动态的, 不同桌子可以使用不同的规则配置. 因此, 每张桌子都有自己独立的RoomRule 实例



* 与玩家关系
  与现实中的桌子类似, 玩家可以与桌子进行特定的交互, 这些交互抽象为 =玩家动作PlayerAction=

  例如, 以象棋为例:
  - 玩家可以站在桌旁观看棋局(站立观看)
  - 玩家可以选择坐下来, 成为对弈者
  - 玩家也可以选择站起来离开, 不在下棋

  这些行为都可以抽象为玩家对桌子的动作
