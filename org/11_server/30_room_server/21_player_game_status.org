  // 用户游戏状态
  enum UserGameStatus {
    kNotInTable = 0;   // 未在桌子上(空闲)
    kSit        = 1;   // 坐下
    kStandUp    = 2;   // 站立(旁观)
    kReady      = 3;   // 准备状态
    kPlaying    = 4;   // 游戏中
  }
#+end_src

桌子状态TableStatus 和 玩家状态UserGameStatus 约束了玩家的动作


#+attr_shortcode: info
#+begin_hint
玩家还有一个重要数据table_id. 描述了玩家在哪个桌子上.
之前玩家动作判断中, 还判断了table_id.

新的逻辑中, 不再需要对table_id 进行判断.
table_id 改为User 的const常量成员, 在User 的生命周期中不会进行变更.
因为桌子销毁的时候, 会同时销毁桌子上的User.

#+end_hint
