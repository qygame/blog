-----
Server Table负责的流程为 游戏开始 - 小局结束 - 大局结束

空闲状态: 桌子创建出来之后的默认状态. 此刻允许玩家坐下
游 戏 中: 游戏开始之后的状态
小局结束: 一局游戏结束之后的状态. 可能有玩家退出, 也可以有新玩家坐下
大局结束: 桌子的最后一个状态. 此状态的时候, 桌子等待被清除. 此时不允许任何玩家动作
