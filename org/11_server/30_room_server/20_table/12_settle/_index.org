=游戏结算SubSettle= 负责组织 Table 内部的游戏结算流程, 包括结算流程的协调、结算数据的整理, 以及结算结果的分发

SubSettle 只负责结算流程的组织与协调, 不负责其他模块的具体业务实现.
- 自身需要处理的事情：由 SubSettle 负责实现
- 其他模块需要处理的事情: SubSettle 负责发起通知、调用接口或协调执行, 不负责实现具体业务

-----


SubSettle 负责组织两种类型的结算:

1. 小局结算
2. 大局结算
