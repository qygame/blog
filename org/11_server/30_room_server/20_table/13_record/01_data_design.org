* 设计原则
  1. 游戏历史数据以桌子数据为唯一权威数据源, 记录一场游戏中桌子自身的数据以及各玩家的输赢信息
  2. 玩家战绩不再单独设计数据结构, 而是统一记录在桌子结算数据中
  3. 数据结构只负责描述业务数据及其职责, 不负责具体的实现

     -----


* 桌子数据
  桌子结算数据分为两类:
  1. TableXjRecord: 小局结算数据, 记录每一小局中所有玩家的输赢
  2. TableDjRecord: 大局结算数据, 记录整场游戏的桌子信息以及所有玩家的总输赢

  #+begin_src C++
    struct TableXjRecord {
      int current_game_count; // 第几局
      std::vector<TablePlayerRecord> players;
    };

    struct TableDjRecord {
      // 桌子数据
      int kindid;
      int table_id;
      int table_mode;
      // 玩家数据
      std::vector<TablePlayerRecord> players;
    };

    struct TablePlayerRecord {
      int uid;
      int chair;
      // 战绩数据
      int score;
    };
 #+end_src


* 玩家数据
  玩家战绩不再单独设计数据结构, 直接使用桌子结算数据

  玩家小局战绩: 记录在对应的 TableXjRecord 关联的 TablePlayerRecord 中
  玩家大局战绩: 记录在对应的 TableDjRecord 关联的 TablePlayerRecord 中
