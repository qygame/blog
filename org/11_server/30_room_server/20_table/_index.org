* 模块职责
  =房间模块= 主要负责管理 =桌子Table=

  ------

* Table 的模块化设计
  Table 只负责自身通用的逻辑流程, 不直接承担任何具体业务功能

  Table 通过扩展模块增强自身功能. 各个扩展模块负责相对独立的业务逻辑, 由 Table 统一组织和协调
  目前主要包含以下模块:

  1. 玩家动作模块: 负责 =玩家动作 PlayerAction= 的处理
  2. 游戏结算模块: 负责小局结束/大局结束后的游戏结算
  3. 游戏记录模块: 桌子数据, 玩家小局战绩, 大局战绩的记录
  4. 录像记录模块: 游戏录像记录
  5. 玩家退出模块: 负责玩家退出Table 的流程
  6. 机器人调度模块: 负责机器人何时进入 Table, 需要多少机器人
