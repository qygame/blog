* 模块职责
  =房间模块= 主要负责管理 =桌子Table=

  ------

* Table 的模块化设计
  Table 只负责自身通用的逻辑流程, 不直接承担任何具体业务功能

  Table 通过扩展模块增强自身功能. 各个扩展模块负责相对独立的业务逻辑, 由 Table 统一组织和协调
  目前主要包含以下模块:

  1. sub_player:   负责 =玩家动作 PlayerAction= 的处理
  2. sub_settle:   负责小局结束/大局结束后的游戏结算
  3. sub_video:    负责录像相关的逻辑
  4. sub_game:     负责子游戏相关的逻辑
  5. sub_dismiss:  负责解散房间
