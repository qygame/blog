* 桌子数据 && 玩家数据
  1. 创建/加入成功, GateServer只是告诉client成功了. 但是数据并不在GateServer
  2. client 拿到成功消息后, 主动去找RoomServer要数据(table数据, 玩家数据). 相当于第一次进入房间.
     client: AskRoomData&&Users
     RoomServer: 返回table数据 和 玩家数据
  3. 后续玩家状态的更新, 由RoomServer主动推送


  -----

  玩家A加入房间 -- 广播A玩家数据给桌子上已有的玩家
                -- A玩家因为是新加入的房间, 会主动拉取房间数据和玩家数据(包含了玩家A)

  玩家A坐下     -- 广播A玩家数据给桌子上已有的玩家
                -- A玩家如果是从status:加入房间 -> status: 坐下. 那么广播的时候也会给A
                -- A玩家如果是直接坐下, 会主动拉取玩家数据(包含了玩家A)
