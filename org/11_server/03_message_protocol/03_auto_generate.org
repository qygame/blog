* 自动生成
  代码自动生成 =消息协议处理函数的声明= && =分发函数=
  使用的时候只需要实现处理函数即可

  比如 sub_login.proto 中定义的sub消息:
  代码会自动生成sub_login.handle.sub.pb.h(处理sub消息) & sub_login.handle.cmd.pb.h(处理cmd消息)
  使用的时候, 只需要实现对应文件中的函数


  #+attr_shortcode: info
  #+begin_hint
  为了消息协议与处理函数一一对应 (删除过时的处理函数, 找到未处理的消息协议)
  自动生成的 =消息协议处理函数的声明= 放在了class中
  #+end_hint
