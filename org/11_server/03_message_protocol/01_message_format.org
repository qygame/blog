* 命名规范

  |           | 规范                      | 例子               |
  |-----------+---------------------------+--------------------|
  | sub消息号 | 1.驼峰式命名              | kSubQueryGoldRooms |
  |           | 2.kSub 表示client->server |                    |
  |           | 3.kCmd 表示server->client |                    |
  |-----------+---------------------------+--------------------|
  | 结构体    | 消息号去掉前缀'k'         | SubQueryGoldRooms  |
  |-----------+---------------------------+--------------------|
  | 处理函数  | 消息号去掉前缀'k'         | SubQueryGoldRooms  |


  #+attr_shortcode: info
  #+begin_hint
  消息号 含义
  1. 第一个字段 k.  表示常量
  2. 第二个字段 归属标志. 可能的赋值:
     - Sub  Client向Server查询
     - Cmd  Server返回给Client
  3. 第三个字段 意图  增删改查
  4. 第四个字段 对象  被op对象 -- 可以没有
  5. 第五个字段 消息号含义
  #+end_hint
