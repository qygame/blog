=子游戏 (SubGame)= 是对 Table 游戏流程的进一步细化和补充

Table 是一个高度抽象的概念, 只定义通用的游戏生命周期, 包含三个核心阶段:
- 游戏开始
- 小局结束
- 大局结束


Table 不关心一场游戏具体如何进行, 也不涉及具体的游戏玩法
而 SubGame 则负责补充 [游戏开始] 到 [小局结束] 之间的具体游戏流程, 包括游戏内部的阶段划分、玩家交互及游戏规则处理等

SubGame 也是从 [游戏开始] 作为逻辑入口的
