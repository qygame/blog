* TODO 创建房间流程
  1. client 创建房间, 携带房间标志kindid 和 =房间配置= 数据. 比如2人, 4局
  2. GateServer 检查玩家是否已在RoomServer中
  3. GateServer 检查kindid对应的RoomServer是否已启动
  4. GateServer 转发kindid 和 =房间配置= 数据给对应的RoomServer
  5. RoomServer 根据client发送的 =房间配置= 数据 构造 =RoomRule=
  6. RoomServer 判断玩家门票是否满足
  7. RoomServer 创建table
  8. RoomServer 主动让玩家坐下
  9. RoomServer 通知GateServer 结果
  10. GateServer 通知client 创建成功, 进入子游戏
  12. RoomServer 游戏开始的时候, 扣除门票

  #+attr_shortcode: info
  #+begin_hint
  门票扣除可以在RoomServer中进行, 但必须RPC到ActorServer中进行实际处理.

  例如: RoomServer中门票扣除20钻石;
  实际是RPC到ActorServer中, 在ActorServer中进行-20钻石的计算, 并返回结果给RoomServer
  #+end_hint
