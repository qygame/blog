游戏模块 处理:

1. 下发 =房间配置= 给client
2. 创建房间流程
3. 加入房间流程

-----

* 创建房间流程
  1. client 创建房间, 携带房间标志(kindid或tableid) 和 =房间配置= 数据. 比如2人, 4局
  2. GateServer 检查
     - 对应的RoomServer是否已启动
     - 玩家是否已在RoomServer中
  3. GateServer 检查通过后, 转发房间标志 和 =房间配置= 数据给对应的RoomServer
  4. RoomServer 创建table
     - 构造房间规则 =RoomRule=
     - 校验玩家门票
     - 创建Table
     - 创建User
     - 玩家入座 User Sit on Table
  5. RoomServer 处理成功后, 通知GateServer
  6. GateServer 通知client创建成功
  7. client 主动去拉取房间数据&&玩家数据, 完成子游戏场景的初始化

  #+attr_shortcode: info
  #+begin_hint
  门票扣除可以在RoomServer中进行, 但必须RPC到ActorServer中进行实际处理.

  例如: RoomServer中门票扣除20钻石;
  实际是RPC到ActorServer中, 在ActorServer中进行-20钻石的计算, 并返回结果给RoomServer
  #+end_hint
