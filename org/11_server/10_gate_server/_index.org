路由逻辑:
client -> Server
GateServer 通过UserSession, 知道玩家所在的业务server id
通过Server List, 获得server_id 对应的session
从而完成 client_session -> UserSession -> Server session 的路由

Server -> Client
Server 来的消息会携带uid, 从而直接获得UserSession -> client_session


这么看, GateServer 确实不处理业务逻辑
