* 路由策略
  路由策略用来指导GateServer 如何选择业务Server.
  业务Server 不同, 使用的策略也不一样, 策略一般依赖 =UserSession= 和 =ServerList=

  1. 不持有玩家数据的Server, 如RankServer, TaskServer 等,
     可以根据ServerInfo 来选择合适的策略.
     比如可以使用轮询, 服务器负载等
  2. 持有玩家数据的Server, 比如 RoomServer,
     应该根据 =UserSession= 中的 room_server_id 来找Server
  3. ActorServer 是比较特殊的一种, 需要根据uid通过一致性Hash 来选择
