=UserSessio= 是client 连接的上下文, 作用:

1. 用于管理已经通过认证的用户会话
2. 维护用户与各业务 Server 之间的关联关系


-----
* 设计目的
  GateServer 是 Client 与业务 Server 之间的通信入口
  当用户通过 GateServer 完成认证后, GateServer 创建对应的 UserSession, 用于记录用户身份以及 =当前用户所在的业务 Server=
  例如:
  1. ActorServer: 用户所在的ActorServerId
  2. RoomServer: 用户所在的RoomServerId


  如果用户已经进入某个业务 Server, 该 ServerId 就应该同步记录在 UserSession 中
  这样, GateServer 就可以根据 UserSession 中记录的 ServerId, 将 Client 的请求路由到对应的业务 Server


  #+attr_shortcode: info
  #+begin_hint
  UserSession 中 ServerId 的生命周期:
  1. 业务 Server 接管用户时注册
  2. 用户离开时注销
  3. Server 异常断线时清理或重新绑定
  #+end_hint
