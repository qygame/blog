=服务发现= 模块用来维护服务器列表 =ServerList=. ServerList 作用:

1. 维护当前可用的业务Server 及其连接, 解决目标Server 在哪里、是否可用的问题

------

* 流程
  GateServer 通过 Service Center 获取和维护Server List.

  1. GateServer 启动后, 向Service Center 获取当前可用的ServerList, 并主动与各Server 建立连接
  2. GateServer 订阅Service Center 的服务变更事件.
     1) 有新Server 上线, 主动建立连接
     2) 有Server 下线, 关闭对应连接
     3) Server 信息变化时, 更新对应信息
