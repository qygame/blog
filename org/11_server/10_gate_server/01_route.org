* 路由总览

1. Client -> Server: GateServer根据 =路由策略= 选择业务Server
2. Server -> Client: Server 消息携带uid. GateServer 查询 =UserSession= 找到对应的client session

-----

* 路由策略
  路由策略用来指导GateServer 如何选择业务Server.
  业务Server 不同, 使用的策略也不一样.

  | 业务Server  | 策略                               |
  |-------------+------------------------------------|
  | ActorServer | 根据uid 通过一致性Hash             |
  | RoomServer  | 根据 =UserSession= 中的 RoomServerId |
  | RankServer  | 轮询                               |
  | TaskServer  | 轮询                               |


  #+attr_shortcode: info
  #+begin_hint
  策略原则:
  1. 不持有玩家数据的Server, 直接轮询即可
  2. ActorServer, 需要通过一致性Hash, 保证Uid 绑定到对应ActorServer
  3. RoomServer 等其他持有玩家数据的Server, 需要在 =UserSession= 中维护ServerID
  #+end_hint
