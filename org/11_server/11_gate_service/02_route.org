1. Client -> Service: GateService根据 =路由策略= 选择Service
2. Service -> Client: 消息携带uid. GateService 查询 =UserSession= 找到对应的client session

-----


* 路由策略
  路由策略用来指导GateService 如何选择其他Service.
  业务Service 不同, 使用的策略也不一样, 策略一般依赖 =UserSession= 和 =ServiceList=

  1. 不持有玩家数据的Service, 如RankService, TaskService 等,
     可以根据ServiceInfo 来选择合适的策略.
     比如可以使用轮询, 服务器负载等
  2. 持有玩家数据的Service, 比如 RoomService,
     应该根据 =UserSession= 中的 room_server_id 来找Service
  3. ActorService 是比较特殊的一种, 需要根据uid通过一致性Hash 来选择
